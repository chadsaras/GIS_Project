Gotcha (for anyone re-authenticating)
  On the Google permission screen tick "Select all". With earthengine-api 1.7.46, leaving any
  box unticked saves a login that Google later rejects (RefreshError invalid_scope), and ee only
  says "Please authorize access ... run earthengine authenticate". Fix: earthengine authenticate
  --auth_mode=notebook --force, tick all. Credentials live in ~/.config/earthengine/credentials
  on the server: never copy them into the repo.

2026-10-01 (3)  Experiment runner for Stages A -> B -> C
------------------------------------------------------------------------------
Overall: about 35% (was about 30%). The modelling code is ready; it is waiting on real data.

Done since last entry
  + scripts/06_run_experiment.py   runs variants V3-V9 (PLAN 8.4) for one round, or all of them:
                                   standardizes GSED on training cells, encodes texts once
                                   (cached), trains Stage A / B per round (cached, so V5-V7 share
                                   one Stage A run), appends POI/road columns for V7-V9, runs the
                                   16-setting Stage C grid on validation, then a 5-seed ensemble.
                                   Writes processed/predictions/{variant}_r{round}.parquet (val +
                                   test rows), reports/tables/stage_c_tuning/{variant}_r{round}.csv,
                                   and models + diagnostics json under models/round{r}/.
  + tests/test_run_experiment.py   end-to-end run of V7 on a tiny fake data directory (also checks
                                   that a second run reuses the caches). All tests pass locally.

How to run on gpu77 (once the inputs below exist)
  for r in 0 1 2 3 4; do
    scripts/run_bg.sh exp_r$r python scripts/06_run_experiment.py --variant all --round $r --threads 8
  done
  Run rounds in parallel, not variants of the same round (they share caches).

Inputs it expects (not built yet)
  processed/cells.parquet   <- Phase 2.11: cell_id, muni_code, keep, gsed_00..63, log_ntl, poi_*, road_*_km
  processed/texts.parquet   <- Phase 4.11: cell_id, text_full, text_raw, text_facts (V5-V9 only)
  V3 and V4 need only cells.parquet, so they can run as soon as Earth Engine + OSM data are in.

Small choices made (mention in report)
  - POI counts and road km both enter Stage C as log(1 + x), then standardized.
  - Stage A diagnostics: recall@1/5/10 only; the linear probe to built-up share (PLAN 5.6) and the
    Stage B neighbour check (PLAN 6.5) are not written yet.

Not done yet
  - V1, V2, V10-V12 baselines (NTL-only, land cover, hybrid, ridge, LightGBM) and the metrics /
    block-bootstrap script (Phase 8)
  - Stage C runtime on real data is unknown (16 settings x up to 3,000 full-batch epochs + 5 seeds
    per variant and round); check it on V3 round 0 first

Done since last entry

                                   z = 32-number layer, outputs z + predicted log NTL per cell
  + src/gisecon/models/stage_c.py  municipal GDP by sum-pooling (PLAN 7.2-7.4): per-cell net with
                                   softplus, index_add_ pooling, "sum" or "logsum" pooling,
                                   full-batch training, LR-on-plateau, 100-epoch rolling-mean
                                   early stopping
  + tests/test_models.py           synthetic-data checks for all three stages (6 tests incl.
                                   test_config pass locally, ~6 s)

Finding
  On the synthetic test, "sum" pooling fit badly (R2 -0.53) while "logsum" fit well (R2 0.66).
  Real municipalities differ by up to 10,000x in cell count, so expect logsum to win
  on validation. Keep both in the tuning grid as planned; watch for this in Phase 7.

Not done yet in these phases (need real data or come later)
  - Scripts that run the stages per round on real data (5.1-5.2 text encoding / scaler,
    6.1 target prep, 7.1 inputs, 7.5 tuning grid, 7.6 5-seed ensemble)
  - Ridge (7.7) and LightGBM (7.8) baselines, predictions.parquet (7.9)
  - Stage A recall + linear-probe diagnostics table, Stage B neighbour check (6.5)

Still blocked
  - Earth Engine project ID (configs/config.yaml gee.project is null) -> no GSED/VIIRS/WorldCover
  - Instructor approval, Kaggle account, Esri licence check (PLAN 0.1, 0.8, 4.1)
